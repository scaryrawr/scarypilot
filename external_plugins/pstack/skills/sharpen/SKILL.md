name: sharpen
description: "Make a task deeper, not bigger, then rewrite the prompt. Use for /sharpen."
---

Make a deeper version of the user's task, not a bigger one. Before rewriting it, do four things:

1. Say what a top professional in this field would do that the user is not asking for.
2. Name the rawest material they would start from instead of already digested summaries.
3. Name the specific methods and tools they would use.
4. Say what, other than you or the user, would show the result is right.

Then rewrite the prompt to ask for exactly that. Leave the user's choices open instead of deciding them.

Return the rewritten prompt; do not do the task. Respect the requested mode and scope. Sharpening does not authorize implementation, publication, or irreversible actions.
