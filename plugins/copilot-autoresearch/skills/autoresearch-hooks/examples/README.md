# Hook examples

Copy the closest example into `.auto/hooks/`, adapt it, and mark it executable.
The files here are references and intentionally are not executable.

## Before

| Script | Purpose |
| --- | --- |
| `external-search.sh` | Fetch external material from a query inferred from agent notes |
| `qmd-search.sh` | Query a local qmd documentation index |
| `anti-thrash.sh` | Suggest a structural rethink after repeated discards |
| `idea-rotator.sh` | Surface the next unchecked idea |
| `hypothesis-reflection.sh` | Ask a cheap model to critique a failed hypothesis |
| `context-rotation.sh` | Archive the tail of an oversized prompt |

## After

| Script | Purpose |
| --- | --- |
| `learnings-journal.sh` | Append one durable summary line per run |
| `macos-notify.sh` | Show a native macOS notification on a new best |
| `auto-tag-winners.sh` | Add a sortable Git tag for every new best |
